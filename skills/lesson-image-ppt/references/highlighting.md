# 高中政治复习课的标注判断

目的不是找“重要词”涂色，而是让学生看出：这条知识是什么、从哪几个角度展开、关键判断成立的条件是什么、答题时需要完整表述什么。先判教学功能，再决定标注范围和样式；不能对某个词建立全课通用的上色词典。

## 贴近参考课件的两种页面

- 导航图：白底、黑字、细黑边无填充的课/框节点、外橙内蓝的分级括线。课—框—目—知识点及记忆线索。标题中的核心概念少量红色；叶节点用黄色标记知识点入口、必要线索和原稿星号。参考图的黑字、红字、黄底具有不同任务，不能全部改为青蓝。
- 讲解页：保留样本已沿用的深蓝目标题、青蓝次级标题、浅蓝框线和完整原句。青蓝加粗是关键命题，黄色补充标出并列分析角度。不要因导航图使用黑字就把全套讲解页重新换风格。

参考图可以指导形式和分析，不能替代原教案提供内容。参考新增的“对比意识”“特点4个”等，不写入原稿讲解；同样不能凭经验新增高考频率、必考或得分值。完整原句、编号、★仍保留。

## 选择依据

| 教学功能 / role | 选择标准 | 第四课的例子及理由 |
| --- | --- | --- |
| 章节核心 / `topic-key` | 只用于导航层级标题。挑出能区分框、目的核心概念，保留周围黑字作为完整标题。 | 框标题中的“认识”“实践”“真理”；目标题中的“客观”“具体的有条件”“过程”。红色在此用于知识定位，并不要求制造另一条对比。 |
| 知识点入口 / `knowledge-anchor` | 同级小点的判别词；看这些词应能辨认每一条在讲什么，不能只是通用“含义”“重要”。 | “来源、动力、唯一标准、目的”区分实践对认识的四种作用。标注范围尽量包含会改变性质的限定语，如“唯一标准”。 |
| 并列分析角度 / `analysis-axis` | 回答同一个问题的不同角度，是后文论证的短主语/分类轴；同组保持同样样式。不是所有名词，也不把一整串原因清单当短角度词。 | “对象、主体、基础”分别提示认识无限性的三条依据。其后的“无限的、变化着”“世代延续”“不断发展”是依据内容，不和角度混为一类。“立场、观点和方法”等具体原因清单通常沿用青蓝关键表述，不整串改黄。 |
| 定义判定核 / `definition-core` | 能把该概念与相近概念区分开的关系或属性；优先完整短语，避免只标定义的主语。 | 真理定义中的“主观同客观相符合”“正确反映”；实践定义中的“改造客观世界”“物质性活动”。 |
| 逻辑边界 / `logical-boundary` | 范围、条件、程度、唯一性、否定或转折，遗漏会使命题变错或混淆。必须连同所限制的对象核读。 | “同一条件”“同一对象”与“只有一个”成组检查；“最基本的属性”；“并没有被推翻，而是不断地向前发展”。不能突出“多个”却忽略“不可能”。 |
| 发生机制 / `mechanism` | 说明为什么/怎样发生的主干动作及对象，适合还原材料对应路径。 | 实践发展认识的“产生新问题、提出新要求”“提供日益完备的认识工具”“锻炼和提高了人的认识能力”。导航可以摘录，但讲解必须保留全句。 |
| 结论命题 / `conclusion` | 从依据得出的判断，保留判断谓词及必要限定；与依据在空间和播放顺序上分开。 | “无限发展的”“永无止境的过程”；不把“因此”本身当成核心知识。 |
| 方法论要求 / `methodology` | 做法中的行动及对象、条件；能直接提示应当怎样做，而非只标“要求我们”。 | “与时俱进、开拓创新”“在实践中认识和发现真理”“在实践中检验和发展真理”。避免只标“真理”，丢失两组不同动作。 |
| 原稿重点标记 / `source-star` | 仅保留原稿已有的★及其归属；不能推断新星号或考频。 | 将原有★在导航中黄底显示，完整讲解原位置仍保留。 |

这些是基于样本与学科关系的教学解释，不宣称知道教师每一处标色的唯一意图。样本没有证据支持“黄底只用于角度”或“红字只能表示对比”，不能把这两条旧假设继续固化。

## 执行步骤

1. 确定页的知识任务：定义、关系、条件、原因、过程或要求。先写清主干命题与下属解释关系。
2. 找知识点入口和同级分析角度，再找定义判定核、逻辑边界、机制/结论/要求。每处写明原文片段、教学角色、简短具体理由；理由留在制作记录，不出现在授课页。
3. 按页型分配样式：导航核心标题红色；导航叶中选中的入口/关键线索黄底黑字；讲解页分析角度黄底黑字，核心命题青蓝加粗。同一词在不同语境承担不同功能时允许不同样式。
4. 对照样本时分别检查色值和选词范围：当前参考黄底为 `#FFFF00`，不是整块节点填充；色值相同仍可能因整段标签涂黄而不相似。不要机械高亮每个叶的完整 label 或通用“含义／是什么”，优先突出区分相邻知识点的入口、判断核或短线索；同组并列角度保持一致。
5. 从普通正文里撤掉装饰性强调。一般每条先抓一组核心短语，不机械限定比例；若几乎整段都标亮，应检查是否没有区分“角度”和“论据”。参考中少量短线索整段黄底可以保留这种功能，不能扩张为长段全黄。
6. 做“只看标注”与“回读原句”两次检查：前者应能恢复知识结构；后者检查限定、否定、条件和主谓关系没有被颜色误导。标出的词正确不代表标出的组合正确。

典型反例：只标“多个”会遮蔽“不可能”的判断方向；只标“只有一个”却完全忽略同一条件/同一对象，会把有条件命题教成无条件断言；把“认识工具”当作另一种“来源”会混淆来源与动力。检查时看整条命题的功能，不凭关键词命中决定归类。

## 可执行标注计划

使用 `marks`，不要仅凭感觉直接填颜色数组。每个标注绑定原文并保留理由：

```json
{"ref":"无限性依据1","marks":[
  {"quote":"对象","role":"analysis-axis","group":"无限性的三条依据","reason":"提示这一条从认识对象展开，与主体和基础两条依据并列。"},
  {"quote":"无限的、变化着的物质世界","role":"mechanism","reason":"说明对象的性质为何使认识需要持续发展，保留属性与对象。"}
]}
```

导航叶由多个来源拼接时，每处 marks 增加 `evidenceRef`，且 quote 必须同时存在于该原文和可见叶节点；标题引用自身原文即可。各页源ID自定，示例不是固定知识数据库。

运行 `scripts/prepare_marks.py source.json deck.json styled-deck.json --report highlight-review.json`，再将 styled-deck.json 交给 render.mjs。脚本会核对原文、可见文字、角色与页型，转换成原生样式并保留审稿表；它不能判断教学理由是否成立，模型仍须按上表逐项复核。未经解释的旧版颜色数组会报提示，不能算完成新标注标准。

## 验收

- 每一处颜色都有源文、教学角色和可核读的理由；没有“因为重要”这样的空泛理由。
- 同组分析角度标法一致，概念与论据颜色有区分；没有将任意名词批量黄底。
- 条件、唯一性、程度、否定和转折未被漏读，原理—方法论能对应。
- 导航与讲解页各自接近样本的格式；没有为统一视觉而覆盖已有效的页面。
- 查看实际PPT中连续短语的高亮、换行和相邻普通文字；不能只检查JSON存在样式。
