# 可在 WPS 修改的模板

`assets/teaching-template.pptx` 是实际运行时读取的样式来源，不只是效果示例。六页分别为两段、三段、四段讲义，讲义分支，两组答案、三组答案。全部是原生可编辑文字与图形，示例内容不带私人教案。既有单页整课大纲、表格和分析页继续用已认可程序布局，本轮未转换为模板页型。

在 WPS 中复制备份后编辑模板，保留选择窗格内对象名称和16:9页面大小；不要删除/重命名命名对象。可通过 `LESSON_TEMPLATE_PPTX=/绝对路径/模板.pptx` 使用副本，不必改仓库模板。每次生成读取一次，无模型提炼步骤；输出私有 `template-source.json` 记录源文件哈希。

## 当前自动继承的范围

| 命名对象 | 程序实际读取 |
| --- | --- |
| `lesson.body.2.1` | 讲义正文字体、颜色、行距 |
| `lesson.title.2` / `lesson.subtitle.2` | 标题色、关键命题色 |
| `lesson.body.N.1` / `.2`（N=2、3、4） | 两个文本框之间的垂直距离，作为对应段落数量的舒展目标 |
| `lesson.branch.1` / `.2` | 分支间距目标 |
| `question.material.2` | 材料字体、字号 |
| `question.prompt.2` | 设问字号、白字色、蓝底色 |
| `question.theory.2.1` | 答案字体、字号、颜色、行距 |
| `question.application.2.1` | 材料应用颜色；与原理框的距离作为组内间距 |
| `question.application.N.1` / `question.theory.N.2` | 两组/三组答案的分支距离，作为自动分配范围 |
| `question.score.2` | 分值字体、颜色 |
| `question.border.2` / `question.brace.2.1` | 材料框线、答案括线颜色 |

只在上述代表对象修改共用样式；其他页同类示例不自动同步。当前要求直接RGB颜色和显式字体，避免仅改主题导致继承歧义。模板中其余位置、线条、背景、图形结构和字号不是任意编辑即全量继承；这些由脚本负责内容适配。尤其改变节点数量、根叶关系仍需改内容数据，不声称WPS“＋”自动重排。

## 生成规则

模板是样式与间距的权威来源，脚本按源文字重新创建内容，不复制模板示例。不再让模型从模板截图猜字号或逐页推算距离。长内容仍用字体实测、中文合法断行与语义分页；已有来源限定和正文不得删除。旧底稿显式字号/行距具有覆盖作用，必要时清理旧覆盖。模板缺失、对象缺失或负间距应报具体错误，不能悄悄恢复硬编码默认值。

导出器的 lineSpacing 未必被写入OOXML；当前 `template_contract.py patch` 在候选导出后按实际测量参数写入原生固定磅值段落行距（字号磅值×倍率）；百分比行距基于Office字体行框，不能与Canvas的字号乘积等同，保留其他内容。检查原生XML和最终文件预览，不能只看导出器内存截图。模板修改后测试至少覆盖稀疏页、密集页、长句/数字换行和答案页；通过程序检查不等于通过WPS实测。
