# 从目录到教学导航

使用人工参考时先比较实际文件，区分原样沿用、版式修改和内容增补。不要凭印象把人工页上的所有优点归因于“人工改动”。

## 应当吸收的做法

1. 目录图只告诉学生“这一课有什么标题”。教学导航图继续展开每个目下的知识点及最短记忆线索：含义、关系、特点、原因、要求等维度。知识点层级来自原文；提示词用原文可追溯摘录，不自由命题。
2. 原稿全文层与导航层同时存在：导航页提供检索路径，讲解页逐句保留。导航压缩不会授权删去全文。导航可按框拆页，不必模仿参考图的高密度单屏。
3. 用颜色区分教学角色：认识无限性的“对象、主体、基础”是三个并列角度，适合黄底；“无限的、变化着”“世代延续”“不断发展”是各自的依据内容，适合青蓝加粗。这是讲解页的一个实例；导航页黄色还用于知识点入口与必要记忆线索，红色用于层级标题中的核心概念。完整选词规则见 [学科标注标准](highlighting.md)。
4. 先判断关系再选图：定义及对比用表格；分类型要点用同级分支；解释依附原主点用缩进圆点；整组依据与总结分开，结论使用原文“因此”等信号词。
5. 将编号的视觉层级与原文字面分开：保真任务默认保留原编号，避免另外造数字节点。人工参考删掉编号并不等于用户授权删原文。可通过缩进、字号、颜色降低编号干扰；只有用户另行允许的摘要页可以省略原编号。

## 不自动吸收

人工参考中的课堂拓展、对比提示、题目和答案，不是原教案的授权补充。已有讲义写三项、参考摘要写四项时，以讲义为准，并在私下报告指出差异。数学符号、页数、星号和疑似笔误不能按参考擅自“修好”。

从另一套课件复制的“12/17”等页脚必须按新课件重算。参考可能有密排、行距不足等问题，不能把这些也固化。

## 实施顺序

先在 source.json 中登记完整原文；建立每个摘要叶节点→原文ID/摘录证据；再选投影可读的四层图宽度与拆页。实现并验证结构化高亮和括线，不能只把“更像人”写成空泛要求。图片→转录、转录→PPT、教学关系、视觉/WPS分别检查。

## 低成本试跑暴露的失败模式

- 摘录有证据不等于分组有教学意义。每个叶节点先标出所属小点，再给记忆线索，例如“认识：含义；两个阶段”“实践：含义；形式；特点”。不要将认识的定义、实践的定义、三个特点都直接平铺在同一目下，迫使学生猜它们属于谁。
- “来源、动力、标准、目的”应分别在对应叶的开头可见；“反复性”的主体/客体原因应归入反复性，“无限性”的对象/主体/基础应归入无限性，不能把这些子项混成同一级清单。
- 标记必须有教学理由。导航标题中的红色可以用于知识定位，无须捏造对照项；正文中单独“加以对照”不因带有“对照”二字就应变红。黄色不能仅解释为分析角度，也不能无差别覆盖所有重要词。
- 源稿中的非常规用词尤其容易被模型按常识改写。完成转录后应逐页逐行对照图片，并单列检查标题、编号、限定词、疑似错词；不能只复述“已逐页看图”或以自建source覆盖通过自证准确。发现与已有人工核对稿不一致时回到图片裁定，不能盲从任一转录。
- 即使全文覆盖通过，也要查导航关系和断词。五页平铺的导航不一定胜过两页有分组的导航；先解决分类和短语长度，再决定拆页。

- 只有一个框、一个目时，上层课/框放到页眉路径，目作为图的根，扩大知识点区域；不要让重复的单分支层级占去半页。渲染器会自动使用这种紧凑布局，多框/多目时保留完整四层括线图。
