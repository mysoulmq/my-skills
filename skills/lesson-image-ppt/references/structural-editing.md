# 结构编辑与样本样式

人工修改脑图时，用户可能需要增加同级、增加下级或移动整条分支。这是结构操作，不能仅用“所有图形可编辑”回答。

## 当前能力与选型

- 自带 render.mjs 输出原生文本框、框线和括线；它们可以逐项编辑，但 PPT 内没有父子节点模型或“+”自动重排。deck.json 保留生成结构，修改后可重新生成；这不等于教师能在 WPS 中直接编辑树，也不会自动回收教师在 PPT 中的修改。
- 原生 SmartArt 是候选方案：结构及布局由应用维护。必须在实际使用的 WPS 版本测试，不把 Windows 教程中的节点快捷键直接当作 Mac 操作说明，不把 UI 中存在按钮等同于功能往返验证通过。
- WPS 思维导图可能采用云端源文件加文档内预览的形式。回源编辑与 PPT 内原生节点编辑应分别说明；只有预览图、没有可用源文件时，不满足结构编辑要求。不得默默将本地教案上传云端。
- 如原生对象无法兼顾样本样式，可研究可视化树编辑器加确定性排版导出：界面提供同级/下级新增，保留父子关系和样式标注，再生成 PPT。当前 skill 尚未实现该编辑器，不能宣称已经支持；也不能把维护 JSON 当作教师的易用编辑方式。

## 样式仍以样本为准

自动增删结构是额外能力，不授权改变已确认的视觉基准。候选方案须保留样本的白底、薄边框、分级括线、黑字层级、红色标题核心词、黄色重点以及主干/线索的粗细区别。以实际样本比较，不以软件默认皮肤代替设计。正文局部富文本、高亮和教学顺序在重排后仍须成立。

不能承诺现有散落图形可一键转换为保留全部样式的 SmartArt。转换前保留原稿，在独立候选中验证；不要直接覆盖已确认课件。

## 结构验收

在最终使用的 WPS 环境中，用样本式代表页完成以下操作并保存、关闭、重新打开 PPTX：

1. 在一条已有分支添加同级，再添加下级；调整一个节点的层级，并删除测试节点。
2. 检查父子归属、顺序、括线及自动重排；无需逐个挪动其他节点才算结构操作成功。
3. 检查重新打开后仍可修改结构，原文字体、高亮、换行、字号与点击出现顺序仍符合基准；测试新增文字不进入正式教案。
4. 分别记录“元素编辑、结构编辑、样本样式、保存重开”的通过/不通过/未验证。提出候选或发现工具入口只能记录为待验证，不能算完成实现。
