# 按阶段执行的模型分工

读取 `assets/model-routing.json`，这是待验证的配置，不是 Astra 已优于 Sol 的结论。

| 阶段 | 默认配置 | 责任边界 |
|---|---|---|
| orchestration | gpt-6.1-sol / medium | 主流程、脚本、普通构建修复；不顺手重写教学内容 |
| image_transcription | gpt-6-astra / low | 原图识读、忠实整理讲义正文、标记范围和出处；不做压缩式脑图或题目加工 |
| teaching_transform | gpt-6-astra / medium | 脑图概括、综合题对应与答案教学化、选择题短解析、整课编排、精简教学底稿及备注；共享同一份资料理解 |
| teaching_review | gpt-6-astra / medium | 独立检查来源转化、教师表达与完整性，只列具体问题，不再起草全套 |
| 程序 | 无模型 | Word提取、排版、动画、编号、来源与覆盖校验、导出 |

## 复用现有执行器

优先用当前环境已有的 `collaboration.spawn_agent`（等价工具须支持明确模型和推理档位）。`scripts/model_routing.py --stage STAGE --task-name NAME --message-file PRIVATE_PROMPT`只生成调用参数，不运行模型，不另建平台。参数包含`model`、`reasoning_effort`、`fork_turns: none`；父任务实际调用工具并保存工具接受的参数及返回身份。不能通过提示词“你是Astra”代替指定模型，不能用继承全会话模式使覆盖参数失效。

主任务不是指定Sol配置或无法核实时，明确记录本主任务身份未验证；可把本轮执行协调交给明确配置的Sol子代理。不为此中断用户已有任务。仅在用户明确要求新工作会话时使用create_thread，不把内部阶段变成一串用户会话。

1. 识读代理收到原图、课的范围、lesson-image-ppt识读规则，产出一次source及知识定位。忠实正文不得被脑图摘要覆盖。
2. 教学代理收到source、程序提取的题目/答案/解析、适用few-shot及当前skill；可分批处理但复用同一底稿，不把每项加工再交给不同模型，不每题重复读全部样例。脑图和正文分开保存，缺主语、关系、限定或原答案点须局部补足。
3. Sol读取教学产物，按现有脚本生成；仅几何、XML、路径、参数等程序问题自行修复。涉及材料取舍、知识对应或答案表达的修改返回同一Astra教学代理，不能由Sol静默补写后计为Astra成绩。
4. 最终语义复核由独立Astra medium任务读取必要输入及候选输出；不重判原答案，不另写长教案，不重复读取无关会话。内容修订只重验受影响项。

## 记录与失败边界

在私有构建目录保留紧凑执行记录：stage、工具接受的acceptedRequest（明确model/reasoning_effort/fork_turns）、executorResult.agent_id或task_name（按工具实际返回）、原始工具结果定位evidencePath；执行器另有实际runtime元数据时存reportedRuntime。执行器未返回实际模型时标“按已接受配置执行，运行时模型未另行回报”，不拿子代理自称或主会话标签作证明。`model_routing.py --check records.json`检查配置一致，不是独立运行时审计。

局部修订沿用原stage，另记operation=repair，不创造新的阶段名。显式授权的模型对比记录单独保存，并写明对默认配置的覆盖；默认配置检查器会拒绝这些差异，不能通过改stage伪装默认运行。

记录本轮skill版本/哈希和输入摘要。发现子代理改委派、配置不符、模型不可用或无法验证接受配置时，保留已完成数据并说明，不静默换模型/提高档位。不要为了记录成本额外调用模型或追查token。用户明确覆盖配置时记录覆盖范围，不能把覆盖后的运行混入默认配置成绩。

## 小规模验证

变更默认配置先用同一输入、同版skill的小样验证：一个讲义知识组、两道不同任务的综合小问、一题含具体排除理由的选择题。先检查讲义逐点覆盖，再看脑图关系是否完整、材料与知识逐组对应、答案保真及解析限定，不以越短越好。原输入与教学输出分开；共享新识读结果比较教学阶段是允许的，但应披露不是两次独立端到端试跑。

若做Sol/Astra对比，两方使用相同资料/样例/任务与skill哈希，各自独立输出后才对照，不能给其中一方旧成品或更详细提示。比较结果仅适用于该样本，不证明模型普遍优劣。日常生成不重复A/B，不写成本报告或长教案。内容验证不代替最终PPT的视觉与动画检查。
