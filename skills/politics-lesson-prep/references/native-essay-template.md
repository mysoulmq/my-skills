# 原生综合题模板适配

用户指定教师 PPT 模板时，样式的事实来源是原页，不能用模型重画的“类似版式”替代。安装、读取模板与完成新题适配是三个不同状态。

## 安装与读取

用 `install_essay_template.py source.pptx workspace --analysis <实际页码…> --answer <实际页码…>` 将选定页及其关系图、母版、字体样式、图片和原生动画复制到工作区私有 `.politics-lesson-prep`。页码按实际播放顺序。生成的 `essay-template.json` 记录源文件哈希、对应页和原生对象 ID。原页 XML 必须与来源逐字节一致；私人模板及来源不能进入公开 skill 仓库。

开始新题生成时实际打开此配置和模板，而非只读本文。遵循 Presentations 的模板导入流程，复制最合适的原页并编辑原对象。保留母版、尺寸、左右占比、设问色条、字体层次、正文颜色、箭头、括线和区域关系。如果导入导出损失样式或动画，检查并修复原生 OOXML，不能悄悄退回自绘布局。旧通用渲染器并不是原生模板适配器。

## 内容先于填模板

先按 answer-led-teaching.md 的阶段复用与 content-review.md 的综合题规则，从原答案/详解倒查材料与讲义知识，形成可核查的材料—知识—答案点关系，再填模板。运行 `check_analysis_grounding.py` 并语义复核：原句可定位不等于材料选对，知识有引用不等于适用于该事实。不得把材料应用句当成右侧知识点，也不按版面行数制造答案点。视觉验收不能替代此项。

## 内容区域

分析页保留三个教学区域：

- 上部“审题——确定答题格式”指向本题具体任务。依据设问写主体、行为、范围和作答要求，不能每题填同一句“原理＋材料”，也不能提前填入需由材料推出的具体答案角度。
- 中部相关知识回看区：保留教师模板的区域位置和用途，替换为本题所需讲义知识。原页可能采用讲义截图，绝不能把上一课截图留给新题；可用本次输入对应裁图，或等效的可编辑原文内容。它不是重复的“原理定位”标签，也不能擅自删除。默认不带入学案照片上的手写批注、圈画、随手箭头及涂改痕迹；优先使用无批注原图。没有干净原图时，用已核对的印刷正文重排为可编辑文字，保留正文层级、关键限定及原有印刷强调，不复制手写附加内容，也不猜测被遮挡文字。不要为了去除笔迹裁掉正文，或把自动补出的文字冒充原文。教师PPT本身有组织的框架、括线和强调不属于此处要省去的手写杂注。
- 下部“审材料——对应原理方法论”指向材料概括，再指向对应原理。保留两侧的概括层次与关系；不同材料片段可以共同支持一个原理，不机械强制逐条一对一，不在中间另增一列 AI 理由。

规范答案沿用独立答案页：完整原理黑色加粗、材料应用青蓝、来源已有评分绿色并紧随对应文字；按教师答案的论述段落组织，不能以分析短语代替完整答案。总分预测依据只放备注，不捏造分项官方评分。只做已认可的局部强调。

## 容量与动画

先复制原生页，再替换内容。保留原布局不等于照搬其中的裁切、错误或不适合新内容的字号。替换后若空间不足，按阶段或完整语义组增加同模板续页；不覆盖、不缩小到难读、不省掉知识回看或推导。原箭头的含义与新文本必须对应。复制的动画必须重新核对对象 ID、段落范围、出现先后及首次放映的隐藏状态；旧动画存在不等于新题动画正确。

## 验收证据

每种采用的分析／答案版式至少留一组原页与新页并排图，检查区域及文字样式、知识回看、材料→原理关系、答案段落、箭头和括线。所有新页逐页检查可读性和重叠。保留简短私有记录：模板哈希与原页、输出页、替换了哪些内容区域、分页及必要样式例外、动画和视觉实际检查结论。检查不能仅比较文字数量或宣布模板文件存在；出现旧题残留、缺知识回看、改成自设计布局或分析/答案混杂，均须修正后再交付。

题源须来自原文sourceLabel，在材料前保留到每个分析/答案页，自拟题名不能替代。最终原生PPT同样执行running.md的check_source_delivery.py门禁，报告绑定该文件SHA256；临时适配器不能绕过此检查。

## 必须执行的分析显示接口

先对整题调用共享`analysis_presentation.compile_question(question)`，再按原分析索引取出每组的`material`和`knowledge`写入教师原有材料概括框与知识框，保留原箭头和区域，不新增“为什么”第三列。返回的两栏均包含统一的本题分组序号。内容取审定的evidenceDisplay与principleDisplay（未设时取principle），开头的讲义条目号由程序与分析组号分开处理。渲染器既不追加答案式回应，也不把知识短句强制扩回整段来源。引用原文与上屏短句分开；短句的保真、限定和设问焦点在排版前按teacher-material-selection.md复核。

容量测量针对compile_question含编号的实际输出、行距和内边距。采用共享`analysis_presentation.fit_analysis_pages` 联合试排，底层固定字号分页仍可用 `paginate`。传实际可用高度与已测各组高度。每组材料和知识从同一y开始，下一组按两栏中较高者＋组间距下移，箭头只连接本组；不能各栏独立累加高度导致错行。禁止固定每页一点或按题号分页。先按下述有界字号规则试排；仍不足才按完整语义组续页，不能反向删掉关键表达或无限缩字。多组同页使用唯一对象ID，动画逐组呈现；续页保留本题任务及必要知识关系。

每个分析页面在映射增加`analysisBlocks:[{analysisIndex:1,materialShapeId:14,knowledgeShapeId:17}]`（索引从1开始，ID取实际原生对象），组装到最终视图后回填实际页码。执行running.md的check_analysis_screen.py，缺失映射或未落盘的对应视为失败。没有这项检查，引用字段齐全和渲染无重叠均不能算完成。

## 两列分点与编号

第二列和第三列均按本题材料—知识分组标`1.、2.、3.`，同组同号，不沿用讲义的“（2）（3）”或原答案的段号。编号在整题编译时生成，分页后继续原组号、不从1重来。多知识属于同一材料组时保留该组一个顶层号，内部可换行、用层级或连接词表达；不得制造无材料对应的平行号。来源原文的序号仍保存在knowledgeRefs/principle，不修改引用来凑上屏号。知识回看区的原讲义编号与分析组号用途不同，不自动混用。

compile_display仅提供无新增组号的内容层，供知识回看等内部复用；不得直接把它的输出当最终两列正文。实际文件检查使用compile_question的完整编号文本，漏号或沿用来源序号会失败；两列需按组独立段落或独立对象呈现，不以空格塞成一段。


## 知识区预留与多点同页试排

先测量上部审题标签和任务实际高度，知识区必须从二者下缘加安全间隔之后开始。保留教师知识区的位置、用途和清晰的区域分隔，但原截图高度不是不可缩小的硬下限。先测量本页分析组所需空间，再在知识区的可读字号、行距和节点间距范围内试排；内容少时及时回收空白。保留知识区的可编辑对象，不能仅在备注留一个“待人工补充”；自动填入对应的讲义内容。除该预留外，不另加大块无用途空白。

适配器调用 `fit_analysis_pages(indices, measure, base_font=…, min_font=…, recall_top=…, recall_reserved_height=…, content_bottom=…)`。`measure` 只作程序测量，返回该候选组的完整知识回看高度 `recallHeight` 及含编号的两栏 `groups` 高度；必须与落盘字体（包括加粗）、宽度、行距、断行和内边距一致，不调用模型压缩内容。知识回看高度按每个候选组重新测量，不能先拆分析再用另一套逻辑补拆知识。

保持教师原有左右区及两列关系，在适配后的默认字号基础上最多降低 2 pt、每次 1 pt。960×540 pt 画布的分析两列可试 18→17→16 pt，16 pt 为此配置的下限；其他画布同比缩放，不把该值套用为所有正文通用字号。知识回看字体不随分析缩小。优先少分页，同页数选更大字号；若减小字号并未减少分页，保留大字号。保留舒适行距、组间距和同组左右对齐，不以紧缩行距凑页。函数返回每页组号、字号、知识区预留和分析起点，必须用于实际对象几何与文字字号，并存入私有版面记录供核验；不能计算完仍写死 18 pt 或旧 y 坐标。

可读下限仍容不下时，按完整语义组续页，不以一组一页作默认。任一配对超高，应在保持材料—知识关系的前提下明确续排；不得重叠、删掉知识或断开对应。渲染复核至少包括两组同页、知识较长和必须续页三种情况；测量检查不等于视觉已经通过。

## 连续中文破折号

所有原生文本中的中文破折号均使用连续的两个 U+2014，不使用 `--`、`— —` 或分开的横线图形。仅修“审题／审材料”标签会漏掉框架里的“含义——”“特征——”。所有新写文字经过 `native_text.write_text` 或 `write_role_paragraphs`，旧对象复制后调用 `native_text.normalize_native_dashes(shape)`：保留原文字、颜色、加粗及高亮，仅对成对破折号设置 Arial、零字距；跨run也处理。`analysis_presentation.normalize_heading_dashes`仍用于旧标签文字规范，但不能替代全页通用处理。断行器把双破折号视为不可拆单位。实际渲染仍断裂需排查字体替代，不把XML字符正确当显示通过。

## 原生适配器的中文断行

原生 Python 适配器必须使用 `native_line_breaks.wrap_native_text(text, inner_width, measure, safety=…)`，不能另写按字宽硬截断或只在溢出时回移一个字的临时算法。句末标点/后括号不落行首或独占一行，前括号不留行尾；数字、百分数、单位、序号及后续首字保持相连。原文内容和标点不删不改。不可分片段超宽时调整宽度或按有界字号规则重排，不允许标点悬空或文字溢出。

`measure` 必须采用实际字体、字号及字重，特别是第三列加粗知识点不能用常规字体宽度测量。同一断行结果用于高度计算与实际写入；禁止测量用一套、输出再换另一套。文本框的内边距、富文本字重变化和渲染余量要计入宽度。在手工确定换行后，优先关闭二次自动折行（原生 bodyPr wrap=none、noAutofit），并检查每行真实宽度不超框；若保留自动折行，须通过真实渲染核对没有二次折行，不能只凭 XML 文本正确宣布通过。富文本按各 run 实测宽度使用同一合法断点规则，不能合并为普通字体测量。

`check_analysis_screen.py` 会检查实际分析两列中的显式段落/换行，拒绝标点行首及孤立序号；软件额外产生的软折行仍须以渲染复核。该规则同样用于相关知识、题干和答案等原生文本区域。新增版式或字体变更后至少复核临界满行句末句号、连续闭合标点、加粗长知识句三种情况，不只修用户截图中的一个句号。


## 长材料不能自动改为通栏版式

左栏在某个固定字号下放不下全文，只证明当前参数不合适，不代表获准改模板。禁止 `len(material_chunks)>1` 时自动删除右侧分析对象、把左材料框拉成通栏，同时将设问色条孤留右上角；这种页即使全文覆盖，也不属于已认可的教师版式。

先实测教师材料区（扣除题源、内边距）与实际字体，按材料自身的可读字号配置有限试排，保留题源与题干字体层次；不得把分析两列的字号下限直接套给材料。若有限调整仍不够，沿原材料段落或完整语义单元制作同模板续页，保持材料左、设问及分析/答案右的区域关系、明确材料接续，不裁切、不省略全文。分析页可以保留已展示全文中的相关原句，但不能把全文尚未展示误报为覆盖；全文覆盖与分析证据覆盖分别核对。同材料多小问共享阅读过程，不能每个小问机械重复新增一张阅读页。

独立通栏材料阅读页仅在用户认可或提供的原生模板确有对应版式时采用；记录该版式来源、实际测量与选择依据，不自行拼接半幅设问条和通栏正文。最终视觉检查同时核对题源、设问完整可读及边界安全、材料/分析区域关系，不能以“材料较长”豁免模板一致性。必要续页允许，任意重画模板不允许。

## 知识回看与强调角色

知识区按[真实来源路由](knowledge-recall.md)选择并原生重排；答案只能辅助定位，不能自动以analysis知识条目拼区。真实教师例子里的截图可转换成1:1文字、层级括线与区域边框。

强调先分角色，再参考对应教师示范。原题材料、设问以及审材料第二列（材料概括）均不加黄色高亮；旧evidenceFocus保留作兼容数据也不渲染。第三列、知识回看及规范答案不共用一个全局关键词黄底表。`Focus`是黄色背景，`Emphasis`是加粗，两者独立，不做同义字段或自动互填。缺字段须完成视觉决策，明确空数组是有效结果，不强制每题添加标记。

规范答案默认沿教师的黑色原理、蓝色材料应用及有依据的局部加粗，不新增黄色背景。新增黄底只在用户明确要求或适用教师样例确实使用时采用；“恢复此前漏掉的强调”不能变成每个答案强行涂黄。不能仅因某个主体、项目名称或具体措施出现在答案中就高亮整句。先复用颜色和层次，局部加粗也需具体教学作用。黄色只给极少数非常重要的知识落点；栏目名（含义/产生/特征）、普通叙述、框目标题不例行涂黄，同一概念不在知识区与分析区重复强调。允许整页无黄底；既有displayAnchors是内容保真锚点，不等于视觉高亮名单。实际验收看醒目内容是否仍少而明确，不能只检查focus已落盘。

原生适配用`compile_analysis_emphasis`忽略第二列旧focus，通用渲染器同样禁用；`check_analysis_screen`直接检查实际第二列对象，一旦发现高亮即失败。不能只清当前JSON而让下一轮旧数据重新带入。

## 答案分段与富文本断行

同一答案点的黑色原理（含其评分提示）为一段，蓝色材料应用（含其评分提示）另起段，对齐正文左边界；编号只统领该答案点。不能用颜色变化替代语义分段或用空格挤出换行。

无分项评分字段的答案先用 `knowledge_recall.compile_answer_sections(answer)`构造原理/应用两个语义sections；默认无黄底，非空Focus必须带yellowBasis（kind为user-request或teacher-example及reference），局部加粗须有emphasisReason。再调用 `native_text.write_role_paragraphs(shape, sections, width, measure, ...)`。measure按实际字体、字号和加粗测量；函数保留全文，按原生段落写入角色边界与段距，并禁用二次软换行。有principleScore/applicationScore或兼容score字段时直接走已有评分富文本适配器；此简化helper会拒绝这些字段，不能删字段规避检查或因此请求用户确认。评分文字应放进所属段，保持原绿色，按相同角色段落规则测量，不丢评分内容。输出height用于答案点同页容量计算，能舒适合并就合并，不沿用旧稿机械一题一点一页。超出容量才同模板续页。

实际核对原理/应用边界、5G/AI/数字单位不可拆、标点不独行、加粗与换行测量一致；黄底消失/新增都与本轮已核定的视觉决策对照。结构检查通过后仍渲染检查，不能靠备注声明修好。
