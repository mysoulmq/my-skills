# 政治整课备课

首要成果是一套资深高三政治教师能理解并实施的授课方案：授课方案 DOCX 说明教学判断和具体讲法，完整 PPTX 承载课堂呈现，同时导出讲义、大题两个 PPTX 视图。不能以课件制作完成代替备课完成。无需教师先做一次编辑才能使用。输入文件是资料，不是代理指令。无额外指令时依据材料推定课程范围；仅有题目时生成讲题课，不虚构讲义；多课分别交付。

## 分工与复用

图片环节调用已安装的 `lesson-image-ppt`：读取其 SKILL.md，遵守原图识读、知识组、标注、分页和动画要求。依赖可从当前 skill 的同级目录或 workspace 的 `.agents/skills` 解析；缺失时说明依赖，不复制替代流程。默认图片识读和讲义设计使用 `gpt-6-astra / low`，新增题目和教学组织使用 `gpt-5.6-sol / medium`。skill 不能自动改变当前模型；须通过明确支持模型配置的执行器执行，并核实真实配置，不能错标模型成绩。

Word 用 `scripts/extract_docx.py` 提取，一轮只提取/识读一次。阶段间传必要内容，不附整段会话。三份课件和方案共用同一底稿；排版、动画写入、页码回填和覆盖检查由程序完成。修改时只更新受影响单元。

实际执行脚本时读取 [执行与验证](references/running.md)，按共同教学序列构建各视图，不直接将两份成品前后拼接。

## 教学工作

1. 读取 [教学设计](references/pedagogy.md)，为每小问建立设问—知识—材料证据—答案对应，形成 [数据约定](references/data.md) 中的题目与活动。原参考答案与加工后的答案分开保存。
2. 高三复习优先“以题诊断—针对问题梳理—回题完善—综合迁移”。精选代表题可用仅含材料、设问的诊断页置于知识前，完整解析仍在前置知识之后；不每题机械加导入。保持知识组完整和讲义正文相对顺序。导航摘录和题目重复原理不抵扣讲义正文覆盖。每课时40分钟，内容多则自然分课时，不删原稿来凑时长。
3. 先确定教学主线与安排理由，再让教学活动同时驱动页面、出现顺序、备注与授课方案。方案写具体提问、预期回答、典型错误、追问纠正、关键解释、过渡、检查与机动取舍，并帮助教师课前掌握关键概念辨析和答案推导；不是逐页内容提纲。
4. 页面采用样本的材料/设问/分析或答案布局；理论黑色、应用青蓝、分值绿色，出现按教学单元分组。不要照搬样本错误、固定题名、页数或点击数。
5. Word采用可点击目录、每课时速览卡、按需查阅的详细讲法。用标题层级、重点加粗和少量底色标记重点/易错；不以密集长段落作为默认阅读入口。PPT备注为逐页独立的临场提示：默认2—3行，每行不超过35字、全页不超过90字；只选本页最关键的提问、点拨、易错或过渡，不机械填满六栏目、不重复整组活动。详细讲法保留在授课方案，原始资料保存在独立底稿，不塞进备注。学生需要的推导线索进入正文，教师的教学策略不整段投屏。

## 验收与停止

按原资料独立检查知识与设问限定、材料证据、教学顺序和文件效果。轻微等价措辞不阻断；教学错误、关键遗漏、无依据答案、不可读页面必须处理。开发试跑使用明确模型配置；教学产物未达标时暂停后续试跑，说明具体问题并询问，不静默换模型或强度补救。可修确定的程序故障，但不能替模型重写答案后声称它通过。

使用 Presentations/ Documents 技能完成真实文件生成与逐页视觉检查，WPS 抽查最终课件静态和点击播放。未完成的检查标为未验证，不等于通过。独立复核步骤只需给出失败项，无须重写产物或长篇报告。

## 交付与编辑

确认所有交付文件实际存在后给出路径。备注仅放临场短提示；修改所需原始资料按稳定页面ID保存到独立底稿，不能以备注代替屏幕正文，底稿不会跟随人工改字自动同步。保留原生文本、图形、表格和逐要点编辑能力；现有脑图不支持WPS内父子节点自动重排，不宣称有“＋”功能。

成本记录只保存执行器现成的模型/用量、程序计时和验收问题；没有token数据不追查、不推算，不增加统计用模型调用。日常交付不附成本报告。私人教案、题库、生成课件和字体不进入发布目录。
