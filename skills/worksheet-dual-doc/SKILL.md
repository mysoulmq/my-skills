# 作业双版 DOC

输入一个 DOCX，交付两个经过检查的二进制 DOC。不要修改原件。按下述浙江选考规则删除，不自动换题或重写答案。不依赖 computer-use 生成，不默认上传云端。

## 默认值和规则

读取 `assets/defaults.json`。用户没提的元数据直接用默认，不询问编制人、校对人或届别。只有用户明确要求“以后默认”才持久修改。临时要求使用 `--set`；标题从输入主题提取，可用 `--set title=...` 覆盖。不根据系统年份改届别。

硬规则：题目正文（包括综合题材料）宋体五号；题干开头的年份、地域、考试题源单独加全角括号并指定隶书五号，这是明确例外；两版选择题前置空括号、真实悬挂；题号句点后直接接题干，不插空格或制表符；单、两位数题号分别按前缀宽度设置悬挂，不能固定63pt。表格单元格不继承题干悬挂；答案版答案与解析全部红色。不要恢复样本中楷体材料、黑色答案或答案版不悬挂的差异。页眉、题头标识和标题从模板继承。信息栏按样本加粗，编制人起点距纸张左边117.5pt；不能把页面绝对坐标当段落缩进。标识不参与文字环绕，信息栏使用零左缩进、首行缩进和真实制表位，兼顾WPS与LibreOffice。原题的图片文字、强调和表格含义保留。

## 浙江选考与题源

题源含“浙江选考”（含浙江1月、6月选考）的整题删除，两版共用同一筛选结果；浙江模拟、联考和其他省高考保留。选择题连同选项、图表、答案解析移除，后续保留题号前移；综合题仅保留原题号和168pt格式空白，两版都不保留原题内容/答案，不自动补题。综合题空位原号优先于连续编号，例：矛盾观选择题1至13、综合题空位15。明确的选择题题数、每题分值对应总分同步更新，已删综合题的总分不沿用。

有删题时必须额外交付删除记录PDF，列出原文件、原号、题源、原题摘要、处理方式、编号映射。PDF也需要逐页查看，审核哈希匹配才可发布。规则细节和边界见 `references/selection-and-sources.md`。

## 执行

先用 `load_workspace_dependencies` 定位捆绑 Python；必要时设置 `WORKSHEET_PYTHON`。通过本 skill 目录的 `scripts/run.sh` 调用：

```bash
scripts/run.sh inspect /absolute/input.docx --out /absolute/inspection.json
scripts/run.sh convert /absolute/input.docx --out /absolute/output-root
scripts/run.sh convert /absolute/input.docx --out /absolute/output-root --set compiler=李老师
scripts/run.sh verify /absolute/run-directory
```

实际命令使用 skill 的绝对路径。`convert` 每次创建独立运行目录：`input.json` 是可追溯题目结构，`internal` 是中间 DOCX，`candidates` 是最终格式候选 DOC，`qa` 是最终 DOC 的 PDF 与逐页 PNG，`verification.json` 是独立自动检查结果。

1. 先检查 `inspect` 的 errors 和 review_issues。无法归属的内容或特殊对象不能静默丢弃。存在图片与解析边界疑点时查看原文；只允许有记录的明确图题关联。
2. 执行转换。核对保留题数、编号映射、综合题空位、删除记录、图片表格及两版内容一致性。源文件变更需要重跑。
3. 阅读每道题答案和解析，检查明显结论矛盾、缺失答案或评分冲突。脚本只做基本结论匹配，不能宣称完整学科教研已自动完成。不要擅改有争议内容；在报告中定位问题。
4. 打开 `qa/pages` 下**两版每一页** PNG，检查乱码、图片完整呈现、裁切、遮挡、表格、选项和换页。脚本检查通过不代表视觉通过。如果怀疑文字缺失而程序内容检查通过，单独重开该页、局部放大，并用最终 PDF 的文字位置交叉确认，再报告具体缺失；文字提取不能代替图片裁切与重叠检查。
5. 明确格式错误最多修复两轮，每轮重跑并重新审阅。用规则或输入解释修复，不随意重写内容；不能通过压小字号凑页数。
6. 全部通过后按 `references/review.md` 写真实审核记录，执行 `approve`。将 `deliverables` 中已验收的两个 DOC 按下述目录规则打包；发生删除时加入对应删除记录PDF。文件名跟随完整标题：`第4课 探索认识的奥秘.doc`、`（答案）第4课 探索认识的奥秘.doc`；不使用通用“题目版.doc/答案版.doc”交付，不复制样本文件名被截短的尾部。不要自动填“已审阅”来跳过视觉或教研检查。

遇到运行环境问题，先读取 `references/runtime.md` 并尝试自动发现依赖、字体和缓存；字体查找与配置应自动处理，不要求用户手动指定已安装资源。不能把字体替代当成宋体验收成功。macOS 自动把找到的合法本地宋体注册到用户字体目录，并查询 CoreText 验证；不得分发字体文件。WPS 开发复核要打开字体对话框确认实际可用，工具栏显示宋体不足以证明未替代。新装字体后已打开的办公软件可能需要用户保存工作后重启，不自动强退。

## 配置修改

```bash
scripts/run.sh config --set compiler=李老师
scripts/run.sh config --set compiler=李老师 --save-defaults
```

第一条仅显示合并配置；第二条仅在用户明确要求持久修改时使用。未知键被拒绝，字体、答案颜色、悬挂等硬规则不接受普通元数据覆盖。

## 交付目录与压缩包

每份原始文件对应一个以原文件名（不含扩展名）命名的文件夹，文件夹内放原始文件的完整副本、两个已验收DOC、该原文件对应的 `浙江选考题删除记录汇总.pdf`。无删题时不生成空报告。多份输入对应多个文件夹，统一打成一个ZIP；禁止将所有文件平铺，禁止仅用跨原文件的总报告代替各文件夹报告。DOC仍按提取的完整标题命名。原始文件逐字节保留；这是供教师复核的完整包，含原始答案，不能当作仅题目版发给学生。

全部运行审核通过后，用捆绑Python执行 `scripts/package_delivery.py /absolute/run1 /absolute/run2 --out /absolute/作业交付.zip`（脚本路径使用skill绝对路径）。脚本核对原件、两版DOC及删除PDF哈希，拒绝未通过验收、文件已变动或缺报告的运行；同名原件使用“（2）”等文件夹后缀避免覆盖。仅打包上述文件，不夹带中间DOCX、页面预览、审核JSON或字体。既有ZIP不覆盖，使用新的输出文件名。

题源字体验收按用户新确认执行：最终DOC重开后的题源字体属性必须为隶书/LiSu、五号；本机缺少真实隶书时允许渲染器替代显示，不阻止交付。记录预览替代警告，不能宣称已验证真实隶书的字形和换行。正文宋体的实际渲染检查保持不变。自动查找可用隶书，但不再要求用户补齐才能生成。

标题保留样本华文楷体14pt。标题与题源均分别记录指定字体和本机渲染情况；本机预览替代不改变DOC中的指定字体。最终回复用一句话说明真实字体环境的换行未验证，不声称所有平台视觉完全一致。
