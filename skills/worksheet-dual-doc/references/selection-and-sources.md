# 删除与题源标注

selection.py在原始解析后生成筛选计划，不改输入。source_number、原块位置及原题ID保持追溯；number是输出号；removed_questions记录整题删除或综合题空位。inspect入口显示该计划。

仅题干起始处具有明确年份和考试名称的标注识别为题源；正文“2026年是…”不是题源，“浙江省开展…”不是浙江选考。例：2025·温州二模→（2025·温州二模），2023·河北高考→（2023·河北高考）。已有括号不重复添加，标注后的题干正文保持宋体五号；题源隶书五号。边界不明报错，不吞掉正文。

字体必须读取真实family：隶书/LiSu不是华文隶书/STLiti，也不是傈僳文Noto Sans Lisu。resolve_source_font自动查系统用户目录、Office目录、缓存及明确配置的WORKSHEET_SOURCE_FONT_FILE。未找到时保留隶书属性并记录本机预览替代，不据此阻止交付；不能把替代字体宣称为真实隶书。字体资源不随skill分发。

综合题空位另起一页，仅保留原编号、宋体五号和168pt段后留白，不写入替代题目、评分或原答案。在有前序选择题删除时，这个原号可以与上一题不连续；删除PDF解释原因。其他保留题号按前序删除的选择题数量前移。

删除PDF属于外部复核资料；被删题摘要只出现在PDF和运行记录，不能残留在题目/答案DOC正文、隐藏内容、图片或表格中。生成记录不等于人工复核已完成。verify重读输入重建筛选模型、核对原内容/附件、DOC回读字符格式、原号空位与PDF；approve需要DOC与PDF逐页审核声明。

题源字体验收按用户新确认执行：最终DOC重开后的题源字体属性必须为隶书/LiSu、五号；本机缺少真实隶书时允许渲染器替代显示，不阻止交付。记录预览替代警告，不能宣称已验证真实隶书的字形和换行。正文宋体的实际渲染检查保持不变。自动查找可用隶书，但不再要求用户补齐才能生成。
